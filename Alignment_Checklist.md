# New Lesson Intake + Alignment Checklist

## Intake
- [ ] Lesson date identified
- [ ] Institutional Excel template supplied/identified
- [ ] Class duration/time slots identified
- [ ] Course/unit/lesson identified
- [ ] Textbook/workbook materials reviewed
- [ ] Existing slides reviewed
- [ ] Listening/video sources reviewed
- [ ] Google Classroom items reviewed
- [ ] Required assessments identified
- [ ] Homework identified

## Objectives
- [ ] Exactly 3 SMART objectives
- [ ] Each uses observable performance
- [ ] Each has a numerical requirement
- [ ] Each names an assessment/output
- [ ] Each names duration/length where applicable

## Lesson Architecture
- [ ] Warm-up activates relevant knowledge
- [ ] Explicit teaching/modeling is present
- [ ] Controlled practice precedes demanding production
- [ ] Guided production is scaffolded
- [ ] Communicative output is meaningful
- [ ] Objective evidence is collected
- [ ] Feedback is scheduled
- [ ] Transitions connect the cycles
- [ ] Breaks remain intact
- [ ] Final retrieval/cumulative check is included

## PowerPoint
- [ ] Fully editable
- [ ] Established light/navy/indigo system preserved
- [ ] No full-slide rasterization
- [ ] Classroom-readable typography
- [ ] No overlap/cutoff
- [ ] One major teaching purpose per slide where possible
- [ ] Layouts vary by teaching purpose
- [ ] Exercise → separate answer key
- [ ] Speaking tasks contain timing + quantity + prompts
- [ ] Hyperlinks tested

## Homework / Google Classroom
- [ ] Exact assignment names
- [ ] Due dates when supplied
- [ ] Required sections/tasks
- [ ] Length/quantity requirements
- [ ] Target language requirements
- [ ] Submission instructions
- [ ] Relevant restrictions
- [ ] Students are shown where to find the assignment

## Final Cross-Check
- [ ] Objective 1 has preparation, practice, assessment, feedback
- [ ] Objective 2 has preparation, practice, assessment, feedback
- [ ] Objective 3 has preparation, practice, assessment, feedback
- [ ] Excel and slides describe the same lesson
- [ ] Assessment measures what objectives claim
- [ ] Homework extends/reinforces lesson content
- [ ] Timing is realistic
