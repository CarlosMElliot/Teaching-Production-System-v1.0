# Carlos Mercado Teaching Production System v1.0

This repository is the persistent source of truth for building Carlos Mercado's Level 13 / IJEP Saturday lesson packages.

## Purpose
Use this repository in any new ChatGPT conversation to recreate the same planning, pedagogy, SMART-objective standard, slide-design rules, assessment alignment, and homework integration established in the Relative Clauses master lesson and SAT 5-6 lesson plan.

## Canonical workflow
1. Analyze all supplied course materials first.
2. Create exactly 3 measurable SMART objectives.
3. Map the objectives into the institutional lesson-plan cycles and exact time slots.
4. Design assessment evidence before building slides.
5. Build the editable PowerPoint to implement the lesson plan.
6. Integrate Google Classroom/homework in detail.
7. Audit objectives ↔ activities ↔ assessment ↔ slides ↔ homework.

## Start in a new chat
Use this repository as the source of truth, especially `Teaching_Production_System_v1.md` and `New_Lesson_Master_Prompt.txt`. Then upload the new course materials and institutional lesson-plan template.

## Canonical reference artifacts
The repository should also contain the successful SAT 5-6 lesson plan and editable Relative Clauses master deck as reference implementations.
