# Teaching Production System v1.0

This repository is the persistent source of truth for building Carlos Mercado's Level 13 / IJEP Saturday lesson packages.

## Purpose
Use this repository in any new ChatGPT conversation to recreate the same planning, pedagogy, SMART-objective standard, slide-design rules, assessment alignment, and homework integration established in the Relative Clauses master lesson and SAT 5-6 lesson plan.

## Canonical workflow
1. Analyze all supplied course materials first.
2. Create exactly 3 measurable SMART objectives.
3. Map the objectives into the institutional lesson-plan cycles and exact time slots.
4. Design assessment evidence before building slides.
5. Build the editable PowerPoint to implement the lesson plan.
6. Integrate Google Classroom/homework in detail.
7. Audit objectives ↔ activities ↔ assessment ↔ slides ↔ homework.

## Start in a new chat
Use this repository as the source of truth, especially `Teaching_Production_System_v1.md`, `New_Lesson_Master_Prompt.txt`, `Alignment_Checklist.md`, and `FRESH_CHAT_WORKFLOW.md`. Then upload the new course materials and institutional lesson-plan template.

The new chat should fetch and read the repository first, analyze the uploaded course materials, create exactly 3 measurable SMART objectives, populate the institutional Excel plan, build the editable slide deck from that plan, integrate assessments and homework, and run the alignment/visual QA check before delivery.

## What was installed in this repository

The repository was initialized as the durable reference for the Teaching Production System so the workflow can be recalled from a new conversation instead of depending only on chat history or memory.

The following core recall files are stored on `main`:

- `README.md` — entry point and repository usage instructions.
- `Teaching_Production_System_v1.md` — the full source-of-truth specification covering planning, pedagogy, SMART objectives, assessment, homework, and PowerPoint standards.
- `New_Lesson_Master_Prompt.txt` — a compact reusable prompt for starting a new lesson-production workflow.
- `Alignment_Checklist.md` — final QA checklist for objectives, lesson-plan alignment, PowerPoint quality, timing, assessment, and homework.
- `FRESH_CHAT_WORKFLOW.md` — explicit instructions for retrieving and applying this repository from a new ChatGPT conversation.

The system is designed so that a future lesson starts with **source analysis**, not immediate slide generation. The expected workflow is:

**course materials → exactly 3 SMART objectives → institutional time/cycle map → assessment evidence → teaching activities → transitions/feedback → homework → editable PowerPoint → final alignment/visual QA**

The key alignment principle is:

**Objective ↔ preparation ↔ practice ↔ measurable assessment ↔ feedback ↔ slides ↔ Excel ↔ homework**

This means the system should not claim, for example, that students will use six target structures in a 3-minute presentation unless the lesson plan schedules that assessment and the PowerPoint teaches, practices, scaffolds, and launches it.

## Non-negotiable implementation reminders

- Exactly 3 SMART objectives per Saturday unless explicitly requested otherwise.
- Every objective needs a measurable quantity/threshold and a named assessment/output with time or length.
- The institutional Excel lesson plan is the instructional architecture.
- The PowerPoint implements that architecture rather than being generated independently.
- PowerPoints remain fully editable; do not rasterize the deck into slide images.
- Exercises and answer keys remain separate.
- Speaking tasks require context, prompts, target structures, minimum quantities, timing, follow-up questions, and success criteria.
- Google Classroom assignments and homework must be described in enough detail that another teacher could explain them without guessing.
- Use YouTube/external material only when it serves a clear instructional purpose.
- Run the alignment and visual-quality audit before declaring the lesson package complete.
