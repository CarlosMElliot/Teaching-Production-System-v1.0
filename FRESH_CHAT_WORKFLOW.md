# Fresh-Chat Workflow

When starting a new chat, give ChatGPT this repository and say:

> Use this repository as the source of truth for my Teaching Production System. Read README.md, Teaching_Production_System_v1.md, New_Lesson_Master_Prompt.txt, and Alignment_Checklist.md before planning. Then analyze the course materials I upload and build the lesson package.

Repository:
https://github.com/CarlosMElliot/Teaching-Production-System-v1.0

## What the new chat should do
1. Fetch and read the repository files.
2. Study all new course materials before generating content.
3. Build exactly 3 measurable SMART objectives.
4. Fill the institutional Excel lesson plan.
5. Build the editable slide deck from the plan.
6. Integrate assessments and detailed homework.
7. Run the alignment/visual QA checklist before delivery.

## Important
The repository is the durable source of truth. Chat memory can help, but the repository should be consulted whenever a new lesson package is built or the user says “use my Teaching Production System.”
